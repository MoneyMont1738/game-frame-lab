# Sample data (SYNTHETIC)

Everything in this folder is **synthetic**. It was generated by
`gfl/synthetic.py` so the full pipeline can run on a machine without a GPU.
None of it is a measurement, and none of it may be cited as a result.

How it is labeled:

- every file name starts with `SYNTHETIC_`
- `manifest.csv` marks every run `data_kind=synthetic`
- `gfl analyze` writes its output under `results/synthetic/`, prefixes every
  file with `SYNTHETIC_`, and stamps every chart with a banner and watermark
- `gfl hypothesis-check` refuses to run on it

## Contents of `synthetic_lyra_scalability/`

The 12 configs of `configs/lyra_scalability.yaml`, 3 runs each (36 runs), with
three files per run in the same formats the real tools write:

| File | Format |
|---|---|
| `SYNTHETIC_presentmon_<run>.csv.gz` | PresentMon 2.x CSV (a subset of its default columns) |
| `SYNTHETIC_frameview_<run>.csv.gz` | Approximation of a FrameView per-frame log; starts and stops about a second off from PresentMon, as a hotkey-started capture would |
| `SYNTHETIC_nvidia-smi_<run>.csv` | `nvidia-smi --query-gpu=timestamp,memory.used,utilization.gpu --format=csv,nounits` sampled every 500 ms |

The per-frame logs are gzipped to keep the repository small; the parsers read
`.csv` and `.csv.gz` the same way. Real captures are plain CSV and live in
`data/raw/`, which is gitignored.

## What the generator models

The cost model in `gfl/synthetic.py` is invented. It is shaped so the analysis
code meets the situations a real capture produces:

- CPU-bound behavior at low settings and GPU-bound behavior at high settings
- per-frame noise and a slow load cycle, like a fixed camera path through
  heavier and lighter areas
- occasional hitches, much more frequent in the first 10 s (shader compilation
  and streaming), which is why the warmup is dropped
- small run-to-run differences

It is not an estimate of RTX 4070 or Lyra performance.

## Regenerate

```bash
python -m gfl.synthetic
```

Output is deterministic (fixed seeds), so regenerating produces identical files.
